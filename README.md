# Sign up form

Create a basic sign up form that looks like a provided design.

## Overview

Would like to implement relevant concepts I have learned in previous lessons.

### General
- Normalize CSS (Using modern normalize)
- Relative units when it makes the most sense
- Custom font of some sort (self-hosted)
- Psuedo selectors (class, element)
- Positioning (relative, absolute)
- CSS functions and custom properties

### Forms
- Correct form elements for usecase (label, input, textarea, selection)
- If input is used correct type is chosen for usecase
- Form validation
